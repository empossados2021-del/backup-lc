# Spec E2.2 — Tipos de dispositivo e menu Mikrotik

| Campo | Valor |
| --- | --- |
| Status | **Concluída** — verificada em 2026-11-09 |
| Base | PRD v2.0 (F-02), Spec E2 |
| Data | 2026-11-06 |

## 1. Objetivo

Separar switches genéricos de roteadores Mikrotik RouterOS no cadastro e na navegação. Cada tipo terá sua própria entrada no menu lateral e sua própria lista de dispositivos.

## 2. Escopo

### 2.1 Tipos reconhecidos

| `device_type` | Rótulo na UI | Menu |
| --- | --- | --- |
| `generic` | Switch | Switches |
| `mikrotik_routeros` | Mikrotik RouterOS | Mikrotik |

Nenhum dado existente é migrado: registros com `device_type = "generic"` continuam como "Switch".

### 2.2 Formulário de cadastro/edição de dispositivo

Adicionar campo **Tipo** (seleção entre "Switch" e "Mikrotik RouterOS") com `generic` como padrão. O campo é obrigatório.

### 2.3 Rotas

| Rota | Comportamento |
| --- | --- |
| `GET /devices` | Lista apenas dispositivos `device_type = "generic"` |
| `GET /mikrotik` | Lista apenas dispositivos `device_type = "mikrotik_routeros"` |
| `GET /devices/{id}` | Detalhe do dispositivo (qualquer tipo) |

A rota `/mikrotik` usa o mesmo template que `/devices` com título e ícone distintos.

### 2.4 Sidebar

Adicionar item "Mikrotik" abaixo de "Switches" com ícone SVG de roteador:

```
Menu
 ├── Dashboard
 ├── Switches
 └── Mikrotik
```

Regra `aria-current="page"` aplicada normalmente.

### 2.5 Coleta e histórico

Sem alterações: o agendador coleta todos os dispositivos (`list_devices`). Detalhes de coleta e histórico de diff continuam em `/devices/{id}` independente do tipo.

## 3. O que não entra nesta etapa

- Driver específico para Mikrotik (RouterOS API ou SSH): será feito na E6.
- Terceiros tipos de dispositivo.
- Filtros avançados por tipo no dashboard.

## 4. Testes esperados

- `list_devices(type="generic")` retorna só switches.
- `list_devices(type="mikrotik_routeros")` retorna só Mikrotik.
- `GET /devices` não exibe dispositivos Mikrotik.
- `GET /mikrotik` não exibe switches.
- Formulário de cadastro salva o tipo correto.
- Menu "Mikrotik" visível para todos os usuários autenticados.

## 5. Critérios de aceite

- [x] Menu "MikroTik" aparece na sidebar para qualquer papel (admin/operator/reader).
- [x] `GET /mikrotik` lista dispositivos MikroTik RouterOS com título "MikroTik".
- [x] `GET /devices` lista apenas switches genéricos.
- [x] Formulário de novo dispositivo permite selecionar o tipo.
- [x] Todos os testes existentes continuam passando.
