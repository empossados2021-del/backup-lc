# Spec E7.2 — Restore: consulta e download por data

| Campo | Valor |
| --- | --- |
| Status | **Aprovada e concluída** — 2026-11-06 |
| Base | PRD v2.0 (F-08), ADR-005 |
| Data | 2026-11-06 |
| Depende de | E4, E6.1 concluídas |

## 1. Objetivo

Permitir que o operador consulte os backups de um dispositivo por data e faça download do arquivo, sem precisar navegar por uma lista de versões.

## 2. Escopo

### 2.1. Página de restore (`GET /devices/{id}/restore`)

Rota acessível a todos os perfis autenticados (reader+).

**Exibição:**

- Campo de data (`<input type="date">`) preenchido com a data de hoje por padrão
- Botão "Verificar"
- Resultado:
  - Se existe backup para a data escolhida: exibe lista de versões do dia (pode haver mais de uma coleta diária), com hora da coleta e botão "Baixar"
  - Se não existe backup: mensagem "Nenhum backup encontrado para DD/MM/AAAA."

**URL de verificação:** `GET /devices/{id}/restore?date=AAAA-MM-DD`

O formulário usa `method="get"` para que a URL fique compartilhável e o back do navegador funcione.

### 2.2. Serviço (`collector/service.py` — extensão)

Nova função:

```python
def list_versions_by_date(db, device_id, date_str) -> list[ConfigVersion]
```

- `date_str`: formato `AAAA-MM-DD`
- Retorna versões cujo `collected_at` cai dentro do dia (00:00–23:59 UTC)
- Ordenadas por `collected_at DESC`

### 2.3. Link de acesso

No detalhe do dispositivo (`/devices/{id}`), substituir a seção "Versões disponíveis" (que atualmente mostra tabela com link de download direto) por um botão "Restore / Download" que leva para `/devices/{id}/restore`.

A seção de diff entre versões permanece, mas os links de download individuais saem da listagem de versões.

### 2.4. CSS

Nenhum estilo novo necessário.

### 2.5. Testes

| Tipo | O que cobre |
| --- | --- |
| Unit | `list_versions_by_date`: data com backup → retorna versões |
| Unit | `list_versions_by_date`: data sem backup → retorna lista vazia |
| Unit | `list_versions_by_date`: múltiplas versões no mesmo dia → retorna todas, ordenadas |
| Integration | `GET /devices/{id}/restore` → 200, campo de data visível |
| Integration | `GET /devices/{id}/restore?date=AAAA-MM-DD` com backup → botão "Baixar" no HTML |
| Integration | `GET /devices/{id}/restore?date=AAAA-MM-DD` sem backup → mensagem "Nenhum backup" |
| Integration | `GET /devices/{id}/restore` sem autenticação → redirect `/login` |

## 3. Fora do escopo

- Restauração automática de configuração no dispositivo (fora do PRD)
- Comparação entre versões nesta página (já existe no detalhe do device)
- Paginação (dias têm poucas coletas)
